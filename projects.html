  • SetTimer

    Workout logger with an automatic rest timer

    2026
    Web app (PWA)

    A mobile-first app for gym-goers. Log a set and a rest timer starts on its own, so there's no switching to the clock app between sets. It's tied to a goal I care about: keeping a record of my workouts and watching my progress over time.

    • 10 of 10locked-screen alerts on iPhone arrived within 3 seconds
    • 90sdefault rest, adjustable from 15s to 10 min

    The interesting problem

    iPhones freeze a web app's JavaScript when the screen locks, so an in-page timer can't alert you on time. I solved it with server-scheduled Web Push: logging a set schedules a notification on the server for the end of the rest, and logging another set or stopping cancels it. The timer stores an end timestamp rather than a countdown, so it stays accurate after the app is throttled or backgrounded.
